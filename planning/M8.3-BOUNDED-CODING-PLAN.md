Add `legoai_engineering.coding`: immutable explicit objective, constraints and
1–8 targets carrying existing M4 CREATE/UPDATE kinds. DELETE is deferred. No new
distribution, dependency, runtime, mutation API or ADR. ADR-018's placement and
read-for-model-analysis disclosure semantics apply unchanged.

Trusted coding acquisition wraps the existing AuthorizedRepositoryEvidence
composition. Its bound workspace, grant/policy, exact allowlist and clock remain
operator-owned. UPDATE uses its authorized M2 reads. CREATE checks bounded parent
entries plus read_text's MISSING result, under the same authorization, to prove
an existing parent and an absent target as observed. This may conservatively fail
when the bounded parent listing fails. Parent metadata is not sent to the Model.
The operator authorizes this limited parent metadata inspection for CREATE targets.
No new directories, hidden dot-prefixed path components, .git or .venv targets.

Evidence retains each target, exact current RepositoryText and an init-disabled
digest derived with M4 digest_text. No model-supplied digest is accepted. Sort
evidence by path; reject missing/extra evidence and kind mismatch. Existing files
<=8192 UTF-8 bytes each, <=24576 total. Objective <=2048, up to eight constraints
of <=1024 each; serialized prompt <=32768 and total M7 prompt <=49152 bytes.

Coding Agent coding-agent v1.0.0 uses engineering-reasoning and one governed M7
call. Closed JSON: summary, changes, risks, unknowns; changes contain path,
operation, content, reason. 1–8 changes, <=8192 bytes/file and <=24576 generated
bytes total; accepted response <=32768 bytes. Every returned path and operation
must match a selected target, no duplicates/case aliases/ancestors. Empty source
is allowed; NUL and invalid UTF-8 are not. Construct actual M4 FileChange and
RepositoryChangeSet values with trusted preconditions, preserving reason metadata
separately in the same order. All changes validate or no proposal is returned.

Statuses: SUCCEEDED, INVALID_REQUEST (acquisition/budget), MODEL_FAILURE,
OUTPUT_INVALID. Preserve exact AgentResult/effects. Invalid typed request raises
safe constructor errors. No retry/fallback, self-review, mutation, Git, checks,
sandbox, memory, Workflow or Team. Digests are observations; M4 must revalidate
at a separately authorized future apply. Proposal never grants write permission.

Tests: bounds/closed JSON/path scope, derived digests, CREATE parent/absence,
authorization denied before reads/disclosure, symlink containment, one governed
fake Model call, unknown effects, no mutation, architecture and fresh install.
Use existing offline governed demo. Full non-Docker Engineering includes M4,
Analyst and Reviewer; focused Core regressions cover M7/M6.5/Model. No executable
validation internally. One local PowerShell script will include typing/Ruff,
packaging, all three examples and diff check. M8.4 remains unstarted.
