      passing.
- [x] `test_concurrent_governed_chat_calls_only_one_reaches_provider` in
      `tests/integration/composition/test_model_governed.py` -- passing.
- **Guarantee stated precisely:** two concurrent callers holding the same
  `execution_id`'s `CoordinationResult` cannot both reach the `ModelPort`
  call; this is a single-process, single-`ExecutionCoordinator`-instance
  guarantee only. It is **not** a cross-process or cross-restart exactly-
  once guarantee, and it says nothing about whether a network-level retry
  by the HTTP client itself could cause Ollama to receive a request twice
  (out of scope: `OllamaModelAdapter` performs no client-side retry).

## Known limitations (see also `examples/documind/README.md`)

- One Model provider (local Ollama) only; no multi-provider fallback.
- Local, single-operator trust model; no Approval workflow, no untrusted-
  Plugin isolation, no distributed dispatch, no crash/restart-surviving
  operation ledger.
- No exactly-once guarantee across a network failure for the effectful
  Model call (see the Replay section above for the exact guarantee).
- Context budgeting is a character-count approximation, not a real
  tokenizer.
- No OCR/scanned-PDF support; no hosted reranker (identity/truncation
  only); no Agent/Workflow/MCP/A2A construct anywhere in this slice.
