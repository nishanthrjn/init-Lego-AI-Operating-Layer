Input: immutable producer AgentId, objective, 1–8 criteria, one textual proposal,
0–8 explicitly supplied supporting items and ExecutionContext. The trusted caller
owns truthful producer attribution and authorization to disclose each supplied
item to the configured model. No filesystem acquisition is added. Compare producer
identity with the fixed independent-reviewer identity before Model invocation.
Identity separation is not proof of separate models, humans or unbiased reasoning.

Bounds: objective 2048 bytes, each criterion 1024, proposal 8192, each supporting
item 4096, proposal plus supporting items 24576, serialized input 32768, accepted
output 16384. Counts and UTF-8 limits fail explicitly, never truncate. Fixed material
ID `proposal` and unique portable supporting IDs ground citations without pretending
they are repository paths or canonical Evidence. Sort supporting items by ID.

Result distinguishes completed review, invalid submission, model failure and invalid
output. Review opinion: accept, changes_required or insufficient_evidence. Closed
finding categories, info/warning/blocking severity, cited material IDs and a required
action for blocking findings. Reject contradictory opinions, fabricated references,
extra/duplicate JSON fields and unbounded text. Preserve exact M7 effect attribution.
Review is not approval, authorization, mutation or a Workflow transition.
