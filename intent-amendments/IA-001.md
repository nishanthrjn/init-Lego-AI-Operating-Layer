# IA-001 — Python-first reusable component delivery

**Version:** 1.0  
**Date:** 2026-09-22  
**Status:** ACCEPTED — maintainer-directed intent amendment  
**Authority:** Explicit maintainer request to establish Python-first direction;
intent 1.0 §55. Read with intent 1.0, whose historical text is retained.

## Change and scope

LegoAI is a Python-first, production-grade platform and reusable component
ecosystem for composing governed AI capabilities, skills, agents, workflows,
teams, provider integrations, framework adapters, and interoperability
protocols into scalable AI applications. This is the product destination,
not a statement that all those components or production guarantees exist today.

Reusable components are developed once as high-quality Python modules and
consumed across applications. Python is the primary maintained implementation
language beyond the initial reference runtime. External frameworks are optional
adapters; reusable Python components and the governed runtime remain the
implementation foundation. Other conforming implementations remain possible.

## Precise amendment to intent 1.0

This amendment qualifies §§1, 24, 39 and 43 only as to implementation delivery
priority. Language-neutral meaning and interoperability remain required;
equal implementation investment across languages is not required. The future
SDK diagram in §39 is illustrative, not a commitment to parallel ports.
The prohibition on a Python-only library in §43 continues to prohibit
Python-exclusive semantic contracts and closed interoperability. It does not
prohibit a Python-first maintained ecosystem.

§4's conceptual technology neutrality is retained. §49's replacement proof
remains; tests may substitute implementations and production adapters are
added for real needs. No requirement to reproduce every component in C#,
Java, JavaScript or each agent framework follows from those sections.
All other intent rules remain unchanged.

## Permanent delivery constraints

- Capability-first reuse; deterministic work remains deterministic.
- Agents compose bounded capabilities, model policies and optional expertise;
  no giant specialist inheritance tree or self-issued authority.
- Workflows own ordering, state, branches, bounded loops, retries, timeouts,
  approvals, recovery and quality gates; concurrency remains supervised.
- Teams compose Actors and coordinate accountability, never become Actors.
- Preserve SPEC's existing Skill definition; defer Python implementation until
  versioned expertise assets provide concrete reuse beyond existing composition.
- Providers, frameworks and protocols integrate behind replaceable adapters.
  MCP client/server and any A2A/API mapping must preserve governance semantics.
- Real applications drive reusable extraction. ForgeAI consumes the reusable
  Software Engineering Team; reusable components never depend on ForgeAI.
- Preserve v0.1, DocuMind and the Document Pack. Production readiness requires
  scope-specific evidence, not this strategic statement.

Applications may use Capability or Model directly; the full
Application → Workflow/Team → Agent → Skill → Capability hierarchy is optional.
It is a composition illustration, not a change to the dependency matrix.

## Review, alignment and migration

[Impact assessment](../planning/PYTHON-FIRST-IMPACT-ASSESSMENT.md) records the
old/new clauses and affected documents. [ADR-016](../adrs/ADR-016.md) records
the implementation decision. The same-assistant static alignment review found
no required changes to SPEC, Architecture, Contracts, Security, Evaluation,
Conformance or Plugin Spec: all retain neutral semantics and existing owners.
This is not an independent audit or execution qualification.

No existing API, data, distribution name or runtime version changes. Existing
C# references remain behavioral/interoperability references, not mandatory
mirrors. Intent 1.0 history is preserved; future implementation planning cites
intent 1.0 + IA-001. Reversing this delivery priority requires a further
documented intent amendment with impact and migration review.
